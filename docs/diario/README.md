# Diario do Projeto ASV (Migbot)

Registro diario do que foi feito, aprendido e evoluido no projeto.

## Convencoes

- Um arquivo por dia: `YYYY-MM-DD.md`.
- Ordenacao cronologica natural pelo nome.
- Cada arquivo segue o template abaixo.
- Linguagem livre (portugues), foco em "o que aprendi" e "o que evoluiu".

## Template

```markdown
# YYYY-MM-DD - <titulo curto da sessao>

## Contexto
<onde estavamos antes da sessao, qual fase>

## O que evoluimos
<bullets do que mudou no projeto: arquivos, funcionalidades, validacoes>

## O que aprendi
<licoes tecnicas, insights, pegadinhas, comandos novos>

## Problemas encontrados
<bugs/erros + causa raiz + fix>

## Pendencias / Proximos passos
<o que ficou em aberto pra proxima sessao>

## Commits
<hashes/mensagens relevantes do dia>
```
